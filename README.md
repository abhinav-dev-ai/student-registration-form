# student-registration-form
A simple and beginner-friendly Student Registration Form built using HTML. It includes input fields for personal details, email, password, date of birth, gender, course selection, phone number, address, hobbies, photo upload, and form submission/reset options.

# Student Registration Form

A simple Student Registration Form created using HTML5.

## Features

- Full Name
- Email
- Password
- Date of Birth
- Gender Selection
- Course Selection
- Phone Number
- Address
- Hobbies
- Photo Upload
- Submit and Reset Buttons

## Technologies Used

- HTML5

## Project Type

Beginner Frontend Web Development Project
